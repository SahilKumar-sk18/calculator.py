Description :-
A simple calculator built using Python. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

Features :-
Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Simple and easy-to-use interface

How to Run
Make sure Python is installed on your computer.
Download or clone this repository.
Open a terminal in the project folder.
Run the following command:
   python calculator.py
   
Usage :-
Run the program and follow the instructions to perform calculations.

Example :-
Enter first number: 10
Enter operator (+, -, *, /): +
Enter second number: 5
Result: 15
